# Города — игра с ИИ

Классическая игра «Города» против компьютера. Полностью статический сайт — запускается без сервера, работает на телефоне и компьютере, публикуется по ссылке бесплатно.

## Особенности

- Полностью на русском, интерфейс и словарь.
- Адаптивный интерфейс: на телефоне — в одну колонку, на десктопе — широкая рабочая область.
- ИИ с тремя уровнями сложности:
  - **Лёгкая** — случайный ход.
  - **Средняя** — выбирает из лучших 30% ходов.
  - **Сложная** — старается «загнать в тупик», оставляя мало вариантов.
- Словарь ~1300 городов: все города России ([pensnarik/russian-cities](https://github.com/pensnarik/russian-cities), MIT) + столицы и крупные города мира в русском написании.
- Правила букв `ъ ь ы й` — пропускаются, берётся предпоследняя игровая буква.
- Подсказки, счёт партий, мгновенный рестарт.

## Обновление словаря

```cmd
cd cities_game
node tools/build_cities.mjs
```

Скрипт подтянет актуальный список городов РФ, добавит мировые из `tools/world_cities_ru.json` и перегенерирует `cities.js`.

## Локальный запуск

Просто откройте `index.html` в браузере двойным кликом.
Либо поднимите любой простой сервер (нужен только чтобы избежать `file://` ограничений в некоторых браузерах):

```cmd
cd cities_game
python -m http.server 8000
```

После этого сайт доступен:

- локально: http://localhost:8000
- в той же Wi-Fi: http://<IP-вашего-ПК>:8000 (узнать IP: `ipconfig`)

## Публикация по ссылке (открыть с любого устройства в интернете)

Содержимое папки `cities_game/` — это готовый статический сайт. Три простых способа бесплатно получить публичную ссылку:

### 1. Netlify Drop (проще всего, 30 секунд)
1. Откройте https://app.netlify.com/drop
2. Перетащите туда всю папку `cities_game/`.
3. Получите ссылку вида `https://<random-name>.netlify.app` — работает с любого устройства.

### 2. GitHub Pages
1. Создайте репозиторий (например, `cities-game`) и загрузите в него содержимое папки `cities_game/`.
2. В `Settings → Pages` выберите ветку `main`, папку `/ (root)`.
3. Через минуту сайт будет по адресу `https://<username>.github.io/cities-game/`.

### 3. Vercel
1. Установите Vercel CLI: `npm i -g vercel`.
2. В папке `cities_game/` выполните `vercel` и следуйте подсказкам.

## Структура

```
cities_game/
├── index.html    — разметка
├── styles.css    — стили, адаптив под мобилки/десктоп
├── app.js        — игровой цикл и работа с UI
├── ai.js         — логика ИИ и оценка ходов
├── cities.js     — словарь городов
└── README.md
```

## Развитие

- Добавить больше городов: расширить массив `CITY_LIST` в `cities.js` — индекс пересоберётся автоматически.
- Новые режимы (только столицы, только Россия, «длинные города» и т.д.) легко добавить фильтром по спискам.
- Онлайн-мультиплеер: можно надстроить отдельный WebSocket-сервер, клиент уже модульный.
